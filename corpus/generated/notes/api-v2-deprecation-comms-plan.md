# API v2 deprecation — communications plan

Just wanted to drop a quick update here before our standup regarding the [[Pulse]] [[API v2 deprecation]] timeline and how we are looping in our user base. 

After sync'ing with the product team yesterday, we agreed that the messaging needs to be clear, direct, and give folks plenty of runway to move over to the current endpoints, especially the teams still leaning heavily on [[Aurora migration]] guides. 

Noah Fischer owns communicating the Pulse API v2 deprecation timeline to customers. He’s going to draft the initial announcement email and coordinate with support so they have templates ready for any incoming questions. We should make sure the documentation site is fully updated before that goes out, otherwise [[Helios]] and the rest of the support queue are going to get flooded with duplicate tickets.

Let's touch base on Friday to review the draft.
