# Meeting notes template

Use this format for all internal alignment syncs and project reviews. Keeping a consistent structure makes it easier for teammates who couldn't attend to catch up on [[Pulse]] development or [[Aurora migration]] blockers.

# Attendees
- List everyone present

# Agenda / Goals
- Bullet points of what needs to be discussed

# Key Decisions
- Document any final choices made during the call
- Note who signed off on [[Helios]] changes or other technical pivots

# Action Items
- [ ] Task description — @Owner — Due date

---

Feel free to add extra sections if your specific sync requires them, but try to keep the top half standardized so we can quickly scan notes later.
