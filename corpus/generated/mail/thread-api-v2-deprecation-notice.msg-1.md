# Pulse API v2 deprecation timeline

Hi everyone,

I'm writing to share an important update regarding our API roadmap here at Lumen Labs. 

As we continue to roll out improvements across Pulse, we want to make sure everyone is leveraging the most stable, performant version of our platform. To that end, please be aware that Pulse API v2 was originally scheduled for deprecation on 2026-06-01. 

If you are still utilizing v2 endpoints for session replay, error tracking, or performance analytics, we strongly encourage you to migrate to v3 as soon as possible. The newer version offers significant speed improvements, better payload structures, and more robust authentication methods. 

We have put together a comprehensive migration guide in our documentation portal to help make this transition as smooth as possible for your engineering teams. If you run into any roadblocks or have questions about specific endpoints, please don't hesitate to reach out to our support team or reply directly to this thread.
